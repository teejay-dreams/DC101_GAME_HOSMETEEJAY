# DC101_GAME_HOSMETEEJAY

# GAME TITLE: ROCK-PAPER-SCISSOR
# DESCRIPTION: Rock Paper A simple, universal hand game for 2+ players. On a shared signal, players form one of three shapes: rock (fist), paper (open hand), or scissors (two fingers). Rules: rock crushes scissors, scissors cut paper, paper covers rock. Ties are replayed. Used to make quick decisions or for casual fun, with no equipment required.
# TECHNOLOGY USE: Visual Studio Code, Using html,css,and java script.
# INSTRUCTION TO RUN THE GAME:
# STEP 1
Make sure the following files  are in the same folder
*index.html
*style.css
*script.js
# STEP 2
Open the file "index.html" usning web chrome/web browser or go live to run the game
# STEP 3
The game will start and outomatically once the page loads and the game begins.
